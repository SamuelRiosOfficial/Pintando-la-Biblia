# Pintando la Biblia

Libro bíblico interactivo para niños. Aplicación web adaptable a computadora, tablet y móvil, con una interfaz de apariencia artesanal y un primer taller de coloreado.

## Ejecutar localmente

Abre `index.html` en un navegador moderno. No requiere instalación ni dependencias.

## Publicar con GitHub Pages

1. En GitHub abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
4. La web estará disponible en `https://samuelriosofficial.github.io/Pintando-la-Biblia/` cuando termine la publicación.

## Estado

Prototipo inicial: menú, biblioteca de historias, lectura introductoria y taller táctil de coloreado con selección de color, relleno, borrador, deshacer, reinicio y exportación SVG. El progreso aún no se sincroniza entre dispositivos.
